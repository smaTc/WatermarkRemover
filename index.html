CSS Z-Index Wassermark Steuerung

Vordergrund-Text (Scharf & Unberührt)

Dieser Text liegt im Element .content-layer mit einem höheren z-index: 2.

Das Wassermark-Bild befindet sich im CSS-Pseudo-Element ::before auf der Ebene z-index: 1. Dadurch verändert die Transparenz (Opacity) ausschließlich das Bild im Hintergrund, während dieser Text absolut leserlich und unbeeinflusst bleibt.
